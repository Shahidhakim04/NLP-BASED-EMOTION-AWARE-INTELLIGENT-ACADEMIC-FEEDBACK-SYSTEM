1. CORE NLP TECHNIQUES
================================================================================

1.1 TEXT PREPROCESSING
------------------------
Technique : Lowercasing + Regex-based Noise Removal
Implementation: preprocess.py
Description :
  - All input text is converted to lowercase for normalization.
  - Regular expressions (re module) are used to strip non-alphabetic
    characters (punctuation, digits, special symbols).
  - This ensures the emotion model receives clean, standardized input.

--------------------------------------------------------------------------------

1.2 EMOTION DETECTION (Sentiment / Emotion Classification)
-----------------------------------------------------------
Technique : Fine-tuned Transformer-based Text Classification
Model     : j-hartmann/emotion-english-distilroberta-base
Library   : HuggingFace Transformers (pipeline API)
File      : emotion_model.py
Description:
  - Uses a pre-trained DistilRoBERTa model fine-tuned for multi-class
    emotion classification.
  - Detects 7 emotions: joy, sadness, anger, fear, surprise, disgust,
    neutral.
  - Returns probability scores for all emotion classes, sorted by
    confidence.
  - This is a deep learning NLP approach using the Transformer
    architecture (self-attention mechanism).

--------------------------------------------------------------------------------

1.3 ZERO-SHOT TEXT CLASSIFICATION (Topic Detection - ML Mode)
--------------------------------------------------------------
Technique : Zero-Shot Classification (NLI-based)
Model     : facebook/bart-large-mnli
Library   : HuggingFace Transformers (pipeline API)
File      : topic_detector.py
Description:
  - Uses Facebook's BART model trained on the Multi-Genre Natural Language
    Inference (MNLI) corpus.
  - Classifies student text into one of 20 academic topics (Mathematics,
    Physics, Biology, Computer Science, etc.) without any task-specific
    training data — hence "zero-shot."
  - Uses natural language inference (NLI) under the hood to match text
    against candidate labels.

--------------------------------------------------------------------------------

1.4 KEYWORD-BASED TOPIC DETECTION (Fallback)
--------------------------------------------
Technique : Rule-Based / Lexicon Matching
File      : topic_detector.py
Description:
  - A fast keyword-matching fallback method when the ML model is disabled.
  - Predefined vocabulary lists (domain-specific keywords) for each
    academic subject are matched against the input text.
  - Keyword frequency counts determine the primary topic.
  - This is a classical NLP approach using domain lexicons.

--------------------------------------------------------------------------------

1.5 READABILITY ANALYSIS
-------------------------
Technique : Readability Scoring (Statistical NLP)
Library   : textstat (v0.7.3)
File      : advanced_quality_analyzer.py
Description:
  - Uses the Flesch Reading Ease formula, a classic NLP readability metric.
  - Flesch Reading Ease Score = 206.835 - 1.015*(words/sentences)
                                          - 84.6*(syllables/words)
  - Scores between 60-70 are considered ideal for academic writing.
  - The analyzer maps this score to a quality rating (poor to excellent).

--------------------------------------------------------------------------------

1.6 LEXICAL DIVERSITY ANALYSIS (Vocabulary Richness)
-----------------------------------------------------
Technique : Type-Token Ratio (TTR)
File      : advanced_quality_analyzer.py
Description:
  - A classical NLP metric: unique_words / total_words.
  - Measures vocabulary richness in the student's response.
  - A higher ratio indicates greater lexical diversity and stronger
    academic vocabulary.

--------------------------------------------------------------------------------

1.7 SENTENCE SEGMENTATION
--------------------------
Technique : Rule-Based Sentence Splitting (Regex)
File      : advanced_quality_analyzer.py
Description:
  - Uses regular expressions to split text on sentence-ending punctuation
    (., !, ?).
  - Feeds into sentence complexity analysis (average words per sentence).

--------------------------------------------------------------------------------

1.8 STRUCTURAL ANALYSIS (Discourse-Level NLP)
----------------------------------------------
Technique : Discourse Marker Detection + Structural Heuristics
File      : advanced_quality_analyzer.py
Description:
  - Detects the presence of transitional/connective phrases such as:
    "however", "therefore", "furthermore", "moreover", "consequently",
    "additionally", "for example", "in conclusion".
  - These are cue words used in discourse analysis to evaluate text
    coherence and logical flow.
  - Also checks for proper capitalization, paragraph structure,
    and punctuation usage.

================================================================================
4. NLP PIPELINE FLOW (End-to-End)
================================================================================

Student Answer (Raw Text)
         |
         v
[1] TEXT PREPROCESSING (preprocess.py)
    - Lowercase normalization
    - Regex-based noise removal (remove punctuation, digits)
         |
         v
[2] EMOTION DETECTION (emotion_model.py)
    - DistilRoBERTa Transformer model
    - Outputs: emotion label + confidence scores for all 7 emotions
         |
         v
[3] ADVANCED QUALITY ANALYSIS (advanced_quality_analyzer.py)
    - Length Analysis         --> word count scoring
    - Complexity Analysis     --> avg. sentence length
    - Vocabulary Analysis     --> Type-Token Ratio (lexical diversity)
    - Readability Analysis    --> Flesch Reading Ease (textstat)
    - Structure Analysis      --> Discourse markers + paragraph checks
    - Composite Quality Score --> weighted average of above metrics
         |
         v
[4] TOPIC DETECTION (topic_detector.py)
    - Primary: Zero-Shot Classification (BART-MNLI)
    - Fallback: Keyword Matching (domain lexicons)
    - Outputs: primary academic subject + confidence
         |
         v
[5] FEEDBACK GENERATION (enhanced_feedback_generator.py)
    - Combines emotion, quality scores, and topic into
      personalized, context-aware academic feedback text
         |
         v
[6] PROGRESS TRACKING (progress_tracker.py)
    - Logs submission history per session
    - Tracks emotion trends and quality improvement over time
         |
         v
[Final Output]
    - Detected Emotion + Confidence
    - Quality Score (0-100) with dimensional breakdown
    - Detected Academic Topic
    - Personalized Textual Feedback
    - Progress Dashboard
